## ⚡ 诊断：我们的文章为什么没人互动？

### 与今日话题 Top 20 的差距对照

| 指标 | 今日话题热文（典型） | 我们的文章 |
|:----|:------------------|:----------|
| **@今日话题** | ✅ 几乎篇篇都有 | ❌ 三篇全无 |
| **$股票代码** | ✅ 至少2个，多则5-6个 | ❌ 三篇全无 |
| **#话题#标签** | ✅ 1-2个 | ❌ 无有效标签 |
| **第一人称"我"** | ✅ "我调研了…" "我看了年报…" | ❌ 第三方客观描述 |
| **结尾互动钩子** | ✅ "你怎么看XX？" | ❌ 直接风险提示收尾 |
| **封面图** | ✅ 非白底、有质感的行业图 | ❌ 纯白底的蚂蚁线稿 |
| **标题情绪张力** | ✅ "账户在滴血"、"不肯认错的自己" | ⚠️ 尚可但偏中性 |

### 根因一句话

> **不是内容质量不够，是"雪球味儿"不够。** 我们的文字风格更像一篇公众号深度文，而不是一个投资人在雪球上的"第一人称分享+判断"。

## 📋 每篇文章发前检查表

### 必做项（缺一不可）

| # | 动作 | 怎么做 | 效果 |
|:-:|:----|:------|:----:|
| 🔴 1 | **@今日话题** | 在正文开头或结尾写 `@今日话题` | ⭐ 编辑团队手动审核，推荐到今日话题栏目 |
| 🔴 2 | **关联$股票代码** | 正文里提到相关公司时写成 `$恒瑞医药(SH600276)` | ⭐ 出现在该股票讨论页=免费精准曝光 |
| 🔴 3 | **加#话题#标签** | 正文末尾加 `#冷链物流# #医药冷链#` | ⭐ 聚合展示在话题页 |
| 🟡 4 | **结尾互动钩子** | 按公式写（见下） | ⭐ 让人想评论 |
| 🟡 5 | **收藏钩子** | 加一个小清单/对比表 | ⭐ 让人想收藏 |
| 🟡 6 | **封面替换** | 非白底，有质感 | ⭐ 雪球官方明确说白底图降权 |
| 🟢 7 | **第一人称开头** | "我最近看了XX的年报…" | 建立人设和信任 |
| 🟢 8 | **结尾回复评论** | 每篇至少回1条 | 信号给算法：作者在互动 |

### ⚠️ 雪球硬性限制（踩过坑记录）

| 限制项 | 上限 | 说明 |
|:------|:---:|:-----|
| `$股票代码` 总插入次数 | **3次** | 同一只股票多次插入也计数，不能超3个链接 |
| `#话题#` 标签 + `@今日话题` 总数 | **3个** | @今日话题算1个，所以加2个话题标签就到顶（实测） |
| `@今日话题` 出现次数 | **1次** | 出现在开头或结尾均可，不要重复出现 |
| `#话题#` 标签出现次数 | **1次** | 只在尾部统一出现，不要开头和结尾各一套 |

**避坑公式（已验证可发）：**
```
开头：@今日话题（仅提及，不加话题标签）
正文：$股票代码 × 3次上限（优选最核心的标的）
结尾：@今日话题 #话题1# #话题2#（合计3个元素）
```

### 互动钩子公式

```
💬 互动话题：

[一个关于具体标的/利益判断的问题，让人想评论展示自己的判断]

✅ 好例子：你觉得冷链吃到最多红利的是顺丰（做运输的），还
   是精创电气（做仪器的）？
❌ 差例子：你觉得冷链行业怎么样？
```

**好钩子的标准：**
- 有分歧空间（不是yes/no）
- 关联具体股票
- 让人想"秀"自己的判断

### 收藏钩子公式

在正文末尾加一段可收藏的清单：

```
📌 值得收藏的【冷链投资逻辑清单】

1️⃣ 运输端 → 顺丰冷运（650亿营收，但毛利率4.2%）
2️⃣ 设备端 → 精创电气（新能源冷藏车温控设备，市占率XX%）
3️⃣ 仓储端 → 京东物流（自动化冷仓建设进度）
4️⃣ 监管端 → 金域医学（全程溯源方案商）
```

## 🎯 发布节奏优化

### 最佳发布时段（基于已测数据）

| 时段 | 效果 | 建议 |
|:----|:----|:------|
| 🥇 **20:00-21:30** | 最高 | ⭐ 晚间黄金档，发硬核长文 |
| 🥈 **11:30-13:00** | 中等 | ⭐ 午休刷手机，发中等长度文 |
| 🥉 **17:00-18:30** | 一般 | ⚠️ 下班通勤，发短评/互动帖 |

### 周节奏（建议）

| 时间 | 内容类型 | 目的 |
|:----|:---------|:----|
| 周一 **20:00** | 调查笔记：硬核长文（第3期冷链等） | 🎯 主内容输出 |
| 周三 **12:00** | 短帖 + 互动话题（带钩子） | 💬 日常互动维持 |
| 周四 **20:00** | 调查笔记：硬核长文（第4期标准化等） | 🎯 主内容输出 |
| 周五 **17:00** | 数据/调研分享短帖 | 📊 轻内容 |

周三的短帖特别重要——它让读者在日常中看到你，不只靠每周两篇长文刷存在感。

### 短帖选题建议

```
1. "今天看了XX公司的年报，发现一个有意思的数据…"   ← 展示专业
2. "问一个问题：冷链赛道你更看好运输端还是设备端？"  ← 互动
3. "今天XX板块跌了3%，但我觉得…"                  ← 及时观点
4. "推荐一个正在读的行业报告"                       ← 分享资源
```

## 🎨 封面图规则（适配雪球）

| 禁止 | 推荐 |
|:----|:-----|
| ❌ 纯白底 | ✅ 浅灰/浅蓝底 |
| ❌ K线图/行情截图 | ✅ 行业相关实景图或数据图 |
| ❌ 低分辨率 | ✅ 清晰高清 |
| ❌ 有版权争议 | ✅ 原创或免版权 |

**关于我们的蚂蚁配图：** 雪球明确说"勿上传白底、K线图及品质感较低的图片"。蚂蚁配图是纯白底线稿风格。建议：
1. 第3期冷链先换一张冷库/冷藏车的高清实景图
2. 蚂蚁配图等我们研究清楚雪球对封面的具体推荐规则后再用

## 🩺 2026-08-02 全面复盘更新（22篇数据）

> 数据：22篇平均阅读3010，互动率0.10%（正常0.5-2%），22篇100%零转发，68%零讨论。巅峰期(6/29-7/6)平均5450 → 低谷期(7/29-8/2)平均470，跌75%。7/18是分水岭。

### 确诊结论

**L1 账号降权（主因）**：阅读断崖+互动归零=推荐池剔除。触发因素：
- 标签超限（025用了1个@+3股票+3话题=7元素，超3上限）→ 反垃圾系统标记"营销号特征"
- 零互动恶性循环
- 7/21→7/29 停更8天（活跃度权重下降）

**L2 内容调性不匹配（帮凶）**：太"完整"太"正确"，没有争议点，读者无话可说。

**L3 节奏失误（加速）**：发布时间从晚间移到上午 + 停更。

### 立即修复清单（已固化到 writing_workflow.md「雪球互动设计」节）

1. **格式合规**：$股票≤3次；#话题#+@今日话题≤3个；每篇发前对照合规模板
2. **互动3动作**：结尾二选一站队题 + 文中可验证推断 + 文末下篇预告
3. **回复所有评论**：24h内，哪怕一句"感谢阅读"
4. **黄金档发布**：20:00-21:30 长文
5. **恢复节奏**：隔日更，禁止停更>5天
6. **破冰测试**：发短帖（非长文）测账号是否有自然流量——短帖有流量=长文被限；短帖也无流量=整体降权需养号1-2周

### 禁止项（红线）
- ❌ 故意写错数据/留模糊破绽引杠精（砸人设）
- ❌ "点赞过X就发下篇"（诱导互动特征）
- ❌ 超限标签（>$股票3次 或 #话题+@>3个）
- ❌ 纯白底封面 / K线截图封面
