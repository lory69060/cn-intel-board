**关键模式：**
1. **标题里必须有具体标的** — 欧莱新材、中远海特、ROE、玻璃基板
2. **个人经历 + 方法论** — "账户腰斩后"这种标题杀伤力最大
3. **系列连载** — 中远海特(3)说明用户追更
4. **数字爆炸** — 3407%净利暴涨、+211.65%涨跌幅

## 建议：我们的调查笔记怎么改

**不要只写"行业分析"，要写"行业分析 + 具体标的 + 投资推演"**

### 可直接写的新选题

**选题1：「没有标签就没有食品安全」—— 检测认证行业的四只铲子**

把我们第1期(检测认证)的行业分析 + 具体公司 + 投资推演
→ 标题风格：《7月1日三套新规同时落地，谁在背后收"标准税"？》

**选题2：「冷链、减肥药与一辆新能源冷藏车」—— 一个正在爆发的交叉赛道**

把第3期(冷链) + 减肥药(礼来/信达) + 新能源车 + 精创电气
→ 标题风格：《减肥药带火一个被遗忘的赛道，这个铲子公司不到100亿》

**选题3：「你们怕AI太弱，但这个东西7月1日正式上岗了」**

把第4期(标准化窗口) + 落地执行的公司
→ 标题风格：《7月1日起，这些公司必须花钱买认证》
